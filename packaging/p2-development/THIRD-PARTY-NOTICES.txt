USB Vault third-party notices
=============================

This internal evaluation package is not a legal conclusion or a production
redistribution approval.

Argon2
------
The application includes the unmodified 20190702 reference implementation
from the Password Hashing Competition Argon2 project, selected under the
Apache License 2.0. The license text is included under licenses\argon2.

VeraCrypt 1.26.29 installer and patched FormatDLL
-------------------------------------------------
The package includes the unmodified upstream VeraCrypt x64 MSI so controlled
internal testers can install the required Windows kernel driver. USB Vault's
installer displays the complete VeraCrypt license and requires explicit
acceptance before invoking the official MSI in unattended mode. Its SHA-256
and Authenticode signature are checked by the packaging script.

VeraCryptFormat.dll is built from VeraCrypt 1.26.29 commit
b48e31f5b47da7d41025e3f0e02751675e15005a with the narrow USB Vault patch
included under licenses\veracrypt. The upstream license and NOTICE are also
included there. Final distribution and source-offer obligations remain subject
to the planned legal review.

ViKey vendor runtime
--------------------
vendor\ViKey.dll is the original x64 runtime from the locally supplied ViKey
SDK. No explicit redistribution license was found in that SDK package during
this engineering review. Keep this package to controlled internal evaluation
until the supplier provides written redistribution permission.

Microsoft Edge WebView2 Runtime

The package includes the unmodified Microsoft x64 Evergreen Standalone Installer.
Its reviewed SHA-256 and Microsoft Authenticode signature are checked before
