## 需要准备

1. 一张 ViKeyPRO 安全卡。
2. ViKeyPRO加密狗提供的 UserSN、API Key 和用户 PIN。
3. VeraCrypt 1.26.29 驱动。安装程序已放在 prerequisites 文件夹。
4. Microsoft Edge WebView2 Runtime。Windows 11 通常已经自带；本包不重复附带。
5. 只使用可丢弃且另有备份的测试数据。

## 首次运行

1. 将完整包解压到本机固定磁盘，双击 usb_vault_vikey_development_credentials_config.exe。
2. 录入供应方提供的开发凭据并保存，插入安全卡，点击“运行检测”。已有配置可直接检测。
3. 若驱动缺失，点击“安装 VeraCrypt（管理员）”。配置器先验证随包安装器的固定 SHA-256 和可信签名，验证成功后才请求管理员授权。请在官方安装器选择 Install，不要选择 Extract；如要求重启，请先重启 Windows。
4. 若缺少 WebView2，点击“获取 WebView2（微软官网）”，下载并安装 Evergreen Runtime。此按钮只打开官方页面，不自动下载或执行文件。
5. 完成安装后重新运行检测。安装器退出不等于驱动可用，以检测结果为准；全部通过后点击“启动 USB Vault”。
6. 后续可双击 usb_vault_vikey_p2_development_app.exe，无需启动脚本。只读检测可能联网，但不初始化卡或操作容器。

下方命令用于手动核查，日常配置不必执行。

## VeraCrypt 安装程序验证（PowerShell）

Get-FileHash -LiteralPath '.\prerequisites\VeraCrypt Setup 1.26.29.exe' -Algorithm SHA256

必须得到：
DCA9DDEC7934FC0B1C25AC8984DB7D504BFE9F37C21861AC91C67A98ECD3964B

Get-AuthenticodeSignature -LiteralPath '.\prerequisites\VeraCrypt Setup 1.26.29.exe' | Format-List Status,StatusMessage

Status 必须为 Valid。任一验证不符时不要运行该安装程序，请重新获取完整测试包。

## 安装 VeraCrypt（PowerShell）

Start-Process -FilePath '.\prerequisites\VeraCrypt Setup 1.26.29.exe' -Verb RunAs -Wait

## VeraCrypt 驱动验证（PowerShell 或命令提示符）

sc.exe query veracrypt

应看到：
TYPE               : 1  KERNEL_DRIVER
STATE              : 4  RUNNING

若服务存在但未运行，先启动一次已安装的 VeraCrypt；仍未运行则重启 Windows 后再检查。

## WebView2 Runtime 验证（PowerShell）

$id = '{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}'
$paths = @("HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\$id", "HKCU:\Software\Microsoft\EdgeUpdate\Clients\$id")
$paths | ForEach-Object { Get-ItemPropertyValue -LiteralPath $_ -Name pv -ErrorAction SilentlyContinue }

若没有输出版本号，请从微软官方页面安装 x64 Evergreen WebView2 Runtime：
[https://developer.microsoft.com/microsoft-edge/webview2/#download-section](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)

## 无需安装的东西

- 不需要另外安装 Microsoft Visual C++ Redistributable。
- 不需要单独启动 WebView2 Runtime；USB Vault 会在打开界面时自动加载它。

## 重要限制

- 这是未签名的内部开发测试包，不是生产发行版。
- 重新初始化安全卡会销毁当前卡身份，旧身份对应的容器随后无法解开。
- 本版本没有密码恢复功能。
- 开发凭据绑定当前 Windows 用户和当前电脑，更换用户或电脑需要重新配置。
