1006 独立兼容测试版（支持 1010 初始化的 v1 三槽安全卡）

用途：客户比较 1006 与 1010 的界面、操作流程和业务行为。它不是原始 1006 二进制，卡格式与密码保留机制已补入 1010 的兼容实现；不能用它比较原版双槽与新版三槽机制。

来源：1006 交付记录中的提交 38b600610e66c7a08a28f0d185357d2da2f357c2。product.patch 只移植 v1 记录、事务日志、卡助手协议及卡记录服务和相关测试；来源提交、原包摘要及补丁摘要见 source-manifest.json。不含 P5.4 的 v2 登录迁移，也不补入 1006 之后的其他产品功能。

原交付页面与该基线的规范化内容一致，区别为 CRLF/LF。构建时恢复原 1006 交付载荷中的页面字节，编译产物及打包载荷均核对摘要。

复现：导出上述基线到单独目录，在仓库根目录用 git apply --directory=<导出目录的相对路径> 依次应用 packaging/compat-1006-1010/product.patch、independent-install.patch 和 credential-reuse.patch。不得把补丁应用到 1010 主线。按原项目 CMake 流程构建应用和卡助手，使用相同版本的 WebView2 SDK 与已审核的依赖；正式打包构建使用 Release、MultiThreaded、BUILD_TESTING=OFF。精确源码快照和构建证据保存在 out/compat-1006-1010。

兼容行为：同时接受 216 与 292 字节 v1 记录；三槽解锁尝试各位置及原槽号绑定；密码更新保留新密码、当前登录密码及最近另一个密码，第四个密码仍可能淘汰旧密码；初始化使用三槽记录。根密钥继续保留在既有锁页缓冲，不增加卡片角色、密码占用标记或任意长度报文。

安装（当前）：安装器、窗口与开始菜单显示为“1006兼容测试版”，默认目录为 %LOCALAPPDATA%\Programs\USB Vault 1006 Compat，卸载登记为 USBVault1006Compat。独立安装，不覆盖当前 USB Vault；两个版本保留在本机，关闭一个后再打开另一个。本次不提供同时运行验收，安装器继续保留共用互斥与主窗口占用检查。

数据隔离：测试版设置和索引位于 %LOCALAPPDATA%\usb-vault-1006-compat；自己的四个 Windows 凭据目标使用 usb-vault-1006-compat-vikey-dev-*。本次按用户要求新增只读复用：只有测试版四项凭据全部不存在时才读取主版本凭据，支持主版本整组记录与既有三项旧记录；不复制、不迁移、不写入主版本。测试版已有凭据优先；缺项、损坏或访问失败不回退，不混用两份。手动保存仍只写测试版自己的整组凭据，因此同一 Windows 用户下主版本配置有效时首次使用不必重新输入；仍须按需导入测试容器。

共享驱动、WebView2 和实卡仍共用；在卡上更新密码或重置会影响另一版本看到的同一张卡。卸载测试版只清理自己的程序、菜单和登记，沿用 1006 保留用户数据及共享组件的行为。主版本凭据之后改变时，没有本地凭据的测试版下次加载会读取新值。

验证范围：软件专项与原入口、会话回归的实际结果见 DEVELOPMENT_LOG.md 和 out/compat-1006-1010。父令牌受限导致的真实 helper 进程跳过，以及未执行的实卡、真实覆盖安装、重启和跨版本索引验收均不能视为通过。客户首次测试应使用可丢弃卡片和安全盘，先验证登录，再验证密码更新与切回 1010。

交付：安装器只放 out/installers/installer-yyyymmdd-hhmmss/1006兼容测试版.exe；同目录保留测试说明和 SHA256SUMS.txt，同名 ZIP 放 installers 根。EXE 名称按用户本次要求覆盖原 USB-Vault-Setup.exe 命名约定；目录及 ZIP 仍遵循时间戳规则。源码、编译身份、内部载荷与校验报告作为本地证据。首版覆盖式安装包是历史交付，本次独立包取代它作为推荐测试包；未提交、禁止推送。
