## 未通过与限制

1. `vikey_helper_process_tests` 在既有 `development vendor runtime staging` 阶段被“local artifact directory resolves through a redirection”拒绝。此前 FAT32 记录已存在同一失败；本轮未放宽路径安全策略。新增进程级 snapshot/reset 用例位于该失败之后，尚未实际执行，不以协议/日志模拟或 WebView 模拟卡结果替代。
2. 未获得明确可破坏测试卡，未执行真实 SDK 重置、区域外实卡哨兵、拔卡/换卡/断电、安装后首次启动及实际旧容器后果验收。只读 HID 测试通过不等于这些项目通过。
3. VeraCrypt 驱动卸载接口按盘符工作；已在调用前比较完整易失挂载身份，但最后核验与 IOCTL 之间外部软件换挂载的极短竞争不能由当前驱动接口原子消除。查询未知时不提供强制卸载；任何场景都可跳过。
4. 其他软件、旧版本应用与已登录进程可能保留旧密钥和挂载访问；重置不是跨进程撤销。互斥仅协调使用该命名约定的本应用版本。
5. 软件验证覆盖可寻址应用区及日志读回，不承诺芯片内部物理擦除或消除已复制的旧数据；中断后的实际卡状态必须重新插卡识别。
